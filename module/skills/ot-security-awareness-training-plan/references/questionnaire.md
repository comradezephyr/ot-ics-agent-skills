# Questionnaire: Training Plan Input

Answer per role. Answers without specifics are returned for completion.

## Roles and Touchpoints

1. Which roles exist with OT touchpoints? For each: headcount, shifts, sites.
2. Which OT systems does each role touch: HMIs, EWS, controllers, network devices, historian?
3. What authority does each role hold: view only, operate, engineer, approve?

## Incident History

4. Which past incidents involved human behavior: phishing, USB media, misconfigured changes, missed alarms?
5. Which behaviors would have prevented those incidents?
6. Were there near misses worth training on?

## Constraints

7. What production schedule constraints limit training windows per shift?
8. How much time per quarter can each role spend in training?
9. What languages do trainees need?
10. Are there works-council or privacy constraints on recording assessment results?

## Current State

11. What training exists today per role? Content, method, last delivery.
12. How are completions tracked today, if at all?
13. What assessment, if any, exists?
14. What do contractors receive today at onboarding?

## Operations

15. What happens on a failed assessment? Retake, escalation, access restriction?
16. Who owns the training program after this design is approved?
17. What is the budget envelope for content and delivery?
